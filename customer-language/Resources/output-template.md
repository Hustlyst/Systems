# Customer Language report templates

## The language bank update

```text
CUSTOMER LANGUAGE BANK: [segment] | updated [date]
Sources this run: [n] ([kinds]) | Bank total: [n] sources
Previous update: [date, or "first run"]

NEW OR STRONGER PATTERNS
[group]: "[short label]" | [n] sources, [kinds]
  "[quote]" ([label])
  "[quote]" ([label])

FADING PATTERNS (not seen in the last two updates)
- [group]: "[label]"

WORDS CUSTOMERS USE THAT WE DO NOT
- They say "[word]". We say "[word]".

LEADS TO FOLLOW UP (one source only, worth asking about)
- "[quote]" ([label]): ask [who] about it
```

## The copy audit

```text
COPY AUDIT: [asset, for example the homepage hero] | [date]
Copy score: [share]% Backed (last audit: [share]%)

Line                         Mark                 Supporting pattern
"[line]"                     [mark]               [pattern, or none]
...

THE THREE LINES TO FIX FIRST
1. "[line]": [why]
```

## The rewrite

```text
REWRITE: [asset] | [date] | leads with: [group]

[new headline]
  backed by: "[quote]" ([label]), "[quote]" ([label]), [n] sources

[new line]
  backed by: ...

TEST PLAN
Old version against new version on [channel], until [date or
number of visitors]. Success means [measure].
```

## A logged test

```text
- [ ] Log the result of the [asset] test (due YYYY-MM-DD)
```
