# Value Pricing edge cases

These are the situations where pricing from value needs a different approach, and what to do in each.

## The client gave no numbers

Without figures, there is no value case yet, only guesses. Do not price. Write the five questions that would give the numbers, send them, or book a short follow-up call. A price sent without a value case becomes a price compared on rate alone.

## The value is very hard to measure

Brand work, culture work and design often have real value that resists a number. Use the cost of the alternatives instead: what a hire or an agency would cost for the same result. Say plainly in the case that the value is estimated from alternatives.

## The client has a fixed budget

When the client names a budget, check what share of the value it represents. If it covers option 1, show option 1 at the budget and the other two above it, so the trade-off is theirs. If it is below the floor, say so kindly and offer a smaller scope or a referral.

## A procurement team that wants day rates

Some companies require a rate card. Offer the value-priced options first. If a rate card is required, build it so the total for each option matches, and keep the options as the main proposal.

## A repeat client

You know far more now: what the last project actually delivered. Use the last project's real result as evidence in the value case. That is stronger than any estimate.

## Very small projects

Below a few days of work, a full value case takes longer than the project. Price from your floor and past similar work, and keep value pricing for the larger projects.

## The value is huge compared with the work

When the maths points to a price many times above anything you have charged, check the attribution. How much of the result is really due to your work, and how much to their team, their product or the market? Price on your share, and lead with the client's own numbers so the price feels earned.

## Retainers and ongoing work

Price the yearly value of keeping the result going, not the hours per month. Review the value with the client every quarter, because a retainer whose value is never revisited is the first thing cut.
